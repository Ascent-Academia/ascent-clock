# Manrope font

Manrope by Mikhail Sharanda, licensed under the SIL Open Font License 1.1
(https://openfontlicense.org). Latin subset of the variable font (weights 400–800), from Google Fonts.

`manrope-latin-var.woff2` is loaded by `../styles.css`, preloaded in
`../index.html` and included in `../sw.js`'s offline asset list. No external font
request is required. If replacing or renaming it, update all three references
and the service-worker cache name, then verify a reload while offline. Preserve
the font's licence requirements when distributing it.
